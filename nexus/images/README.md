# Images

Nexus page images, tracked in the repo. The background is 1300x372, the gallery images are 1920x1080. The mods-grid thumbnail is not a separate file: Nexus picks it from the uploaded gallery images. The images were prepared by hand from in-game screenshots of the HUD trap list, the same save without and with the mod. The trap icon on the title card is the game's own HUD trap icon (an inline SVG in `CoreUI1.html`).

- `banner.jpg` - the mod page background image (1300x372): the game's trap list without the mod (one long row for each trap, faded at the bottom) and an arrow to the Trapline grid with the "Take All" button.
- `sl-trapline-thumbnail.jpg` - title card (1920x1080): the "Trapline" wordmark and the trap icon beside the Trapline grid with the "Take All" button. Pick this as the mods-grid thumbnail.
- `sl-trapline-comparison.jpg` - before and after (1920x1080): the full HUD with the game's trap list ("Original"), which fills the screen, beside the HUD with the Trapline grid ("Mod").
